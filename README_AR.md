# CANDLA.A.b — الإصدار 3.0

تطبيق Flutter عربي لإدارة مشروع صناعة الشموع:
- إدارة الطلبيات والزبائن.
- إدارة مخزون المواد الخام مع تنبيهات الحد الأدنى.
- وصفة إنتاج لكل شمعة: كمية كل مادة لازمة للقطعة.
- خصم تلقائي لمواد الوصفة عند إضافة طلبية (على أساس كمية الطلبية).
- احتساب تكلفة مواد الإنتاج للطلبيات المسجلة، والمصاريف، والصافي التقديري.
- حفظ محلي على الجهاز، والعملة DZD، وتصميم Rose.

## التشغيل
1. ثبّت Flutter SDK.
2. افتح مجلد المشروع في VS Code أو Android Studio.
3. نفّذ:
   flutter create --platforms=windows,android,ios .
   flutter pub get
   flutter run

## البناء
- Windows: flutter build windows --release (يتطلب Visual Studio مع Desktop development with C++)
- Android: flutter build apk --release
- iOS: flutter build ipa --release (يتطلب Mac وXcode وحساب/توقيع Apple)

## ملاحظات مهمة
- هذا أرشيف مصدر Flutter وليس ملف EXE أو APK أو IPA جاهزاً.
- التخزين محلي على كل جهاز ولا توجد مزامنة بين الأجهزة.
- خصم المخزون يحدث عند إضافة الطلبية، لذلك لا تعدّل وصفة الإنتاج بعد إدخال طلبيات قديمة إلا مع مراجعة الأرصدة.
- إذا حذفت طلبية، لا يعيد التطبيق المواد تلقائياً إلى المخزون؛ صحّح المخزون يدوياً من صفحة المخزون.
- تكلفة الإنتاج تحسب المواد المعرفة في الوصفة فقط. أضف التغليف أو الملصقات ضمن الوصفة، وسجّل الكهرباء والنقل وغيرها في المصاريف.
- الصافي تقديري: المبيعات ناقص المصاريف المسجلة وتكلفة المواد المحسوبة. لا يمثل محاسبة ضريبية أو دفترية كاملة.
- لا يحتوي الإصدار الحالي على إدارة دفعات/مرتجعات أو نسخ احتياطي سحابي.
